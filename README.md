# Asian-Paints-Financial-Model
Comprehensive financial model of Asian Paints Ltd. developed in Microsoft Excel to analyze historical financial performance, forecast future results, and evaluate valuation.
## Model Features

- Historical financial statement analysis
- Integrated financial modeling
- Financial ratio analysis
- Valuation analysis
- Sensitivity analysis
- Interactive financial dashboard

## Skills Demonstrated

- Financial Statement Analysis
- Financial Modeling
- Ratio Analysis
- Sensitivity Analysis
- Microsoft Excel
- Data Visualization
